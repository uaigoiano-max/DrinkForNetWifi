# Código de Conduta

Este projeto busca manter uma comunidade aberta, respeitosa e colaborativa.

Esperamos que participantes:

- tratem todas as pessoas com respeito;
- aceitem críticas técnicas de boa-fé;
- evitem linguagem discriminatória, assédio e ataques pessoais;
- mantenham discussões focadas no projeto;
- respeitem privacidade, consentimento e regras dos eventos.

Comportamentos inadequados podem ser reportados ao mantenedor do repositório. Issues, pull requests e comentários podem ser moderados para preservar um ambiente seguro e produtivo.
